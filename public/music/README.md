# Фоновая музыка

Игра сама подхватит треки, если положить сюда файлы с такими именами:

- `menu.mp3` (или `menu.ogg`) — музыка в лагере/меню
- `battle.mp3` (или `battle.ogg`) — музыка в бою

Форматы: `.ogg` предпочтителен (легче, открытый), `.mp3` как запас — можно
положить оба, движок выберет поддерживаемый. Если файлов нет — игра просто
играет без музыки, ничего не ломается. Громкость и мьют — общий тумблер «Звук».

## Где взять бесплатные треки под пост-апок (проверь лицензию перед заливкой на Яндекс!)

**CC0 (public domain, без указания авторства — самый безопасный вариант):**
- **Post-Apocalyptic Soundscapes** — 38 треков, CC0, специально под пост-апок:
  https://swarajthegreat.itch.io/post-apocalyptic-soundscapes
- **OpenGameArt.org** — фильтр по лицензии CC0, теги "dark ambient", "wasteland":
  https://opengameart.org/  (напр. треки Juhani Junkala — автор CC0-ассетов)
- **FreePD.com** — раздел "Dark"/"Ambient", всё public domain (CC0):
  https://freepd.com/

**Free / royalty-free (обычно требуют указать автора — проверь условия):**
- **NUKE — Post-Nuclear Ambient** (7 треков, royalty-free, кредит автору):
  https://rustedstudio.itch.io/free-royalty-free-music-nuke
- **Pixabay Music** — бесплатно, без обязательной атрибуции, теги "post apocalyptic":
  https://pixabay.com/music/

Рекомендация: возьми 1 спокойный эмбиент-трек для `menu` и 1 напряжённый/ритмичный
для `battle`. Для Яндекс.Игр держись CC0 или явно royalty-free с разрешением на
коммерческое использование в веб-играх.
