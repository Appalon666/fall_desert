# 📦 Документы для публикации на Яндекс.Играх

Папка с готовыми материалами для личного кабинета разработчика (ЛК) Яндекс.Игр
и промтами для генерации графики.

## Файлы
- **[store-listing.md](store-listing.md)** — все поля ЛК: версия, платформы,
  ориентация, языки, возрастной рейтинг, категории, теги, ключевые слова,
  «Как играть», описания (Русский + English): Название, SEO, Об игре, Короткое.
- **[art-prompts.md](art-prompts.md)** — промты для нейросети на генерацию всего
  арта: персонажи (6 кадров), монстры-спрайтшиты (idle/walk/death), оружие,
  главное меню, иконка 512×512, обложка 800×470, кнопки, параллакс-фон. Со
  стайлгайдом, размерами, форматами PNG и правилами именования под код.

## Чек-лист заливки (по требованиям Яндекса)
- [ ] `npm run build` → запаковать содержимое `dist/` в **zip** (внутри `index.html`
      в корне, без пробелов/кириллицы в путях). Размер < 100 МБ.
- [ ] Загрузить архив в ЛК → раздел «Общее» → **Архив**.
- [ ] **Версия** — `0.3.0`.
- [ ] **Платформы** — Десктоп + Мобильные (тач работает).
- [ ] **Ориентация** — Ландшафт (арена 1280×720, соотношение ~1.78 < 2:1).
      Заглушку о повороте в портрете рисует САМА платформа по этой настройке.
      Своей в игре нет и быть не должно (п.1.15) — за неё сняли релиз
      4 сентября 2026; стережёт `npm run check:audio`.
- [ ] **Игра переведена на** — Русский, Английский (SDK-автоопределение реализовано).
- [ ] **Возрастной рейтинг** — 12+ (мультяшное насилие по мутантам, без реализма/крови).
- [ ] **Категории** — **Казуальные, Аркады**. НЕ ставить «Симуляторы»/«Ролевые»:
      именно за это сняли релиз по п.2.3. Теги и ключевые слова — из `store-listing.md`.
- [ ] **Как играть** — из `store-listing.md`.
- [ ] **Иконка** PNG 512×512 (`dock/icon.png`) и **Обложка** PNG 800×470
      (`dock/cover.png`) — залить в ЛК. Файл в репозитории проверен: углы прямые,
      прозрачности нет. Прошлый отказ по п.8.3.3 (скруглённые углы) — значит в
      кабинет была залита ДРУГАЯ версия; перезалить именно этот файл.
- [ ] **Облачные сохранения** — ВКЛ (используется `player.setData`).
- [ ] **Описание (RU/EN)** — Название, Описание для SEO, Об игре, Короткое — из `store-listing.md`.
- [ ] **Название побуквенно** — `Ядрён-Пустошь` (с «ё», с заглавной «П») во ВСЕХ
      полях и на промо. В прошлом черновике стояло «Ядрен-пустошь» — отказ по п.5.1.3.
- [ ] **Права на материалы (п.3.5)** — ответ готовится в `dock/rights.md`; там же
      отмечено, что музыку нужно подтвердить или заменить на заведомо CC0.
- [x] **Лидерборд** — таблица с id `kills` заведена в ЛК (8 августа 2026). Имя в
      коде — `LEADERBOARD` в `src/platform/yandex.js`, единственный источник;
      совпадение стережёт `tests/leaderboard.test.js`. Если рекорд всё-таки не
      появляется — сверять в ЛК регистр (`kills`, строчными), тип значения
      (целое) и направление сортировки (больше = лучше).
- [ ] **Rewarded** — включён (возрождение, ×2 за взятую локацию, ×2 офлайн).
      **Interstitial** — включён, ЕДИНСТВЕННАЯ точка показа: выход из вылазки
      в лагерь (неигровое действие), троттл ≥75 с.
- [ ] Проверить в песочнице Яндекса: реклама, облачные сейвы, языки.

## Соответствие требованиям (код — готово)
- ✅ `LoadingAPI.ready()` вызывается по готовности геймплея.
- ✅ `GameplayAPI.start/stop` вокруг боя и рекламы.
- ✅ Реклама только через SDK; пауза геймплея + звука на время ролика.
      Interstitial (п.4.4): игра реалтаймовая с короткими локациями, поэтому
      показ по игровому действию запрещён — единственная точка вызова — выход
      из вылазки в лагерь (переход в меню), троттл ≥75 с. С кнопок «идти
      дальше» и «смириться и продолжить» реклама убрана 4 сентября 2026.
- ✅ Rewarded — по кнопке, с явным указанием награды; бонус не обязателен для
      прогресса. Награду выдаёт ТОЛЬКО колбэк onRewarded (п.4.5): закрытый
      раньше времени ролик награды не даёт, игрок видит объяснение. Стережёт
      `tests/ads.test.js`.
- ✅ Ни одна пауза не вечная (п.1.14): у рекламы два сторожа (15 с «не
      открылась» и 3 мин «не закрылась»), у окна оценки — 60 с, у скрытой
      вкладки — сверка раз в секунду с `document.hidden`.
- ✅ Оценка игры (`feedback.canReview` → `requestReview`) — единый шлюз
      `Platform.requestReview` в `src/platform/yandex.js`: запрос строго после
      `canReview`, не чаще раза за сессию, под окном игра на паузе и молчит.
      Три точки запроса — взятая локация, новый рекорд на экране смерти и
      кнопка ⭐ в лагере (появляется, только если `canReview` разрешает).
      Раньше третьей локации не просим (`State.reviewUnlocked`). Стережёт
      `tests/review.test.js`.
- ✅ Автоопределение языка через `environment.i18n.lang` + фолбэк на браузер.
- ✅ Облачные + локальные сейвы, автосохранение после действий, слияние по свежести.
- ✅ Мьют звука; шрифт и все ассеты самохостинг (без внешних CDN).
- ✅ Рекорд в таблицу уходит через `State.leaderboardScore()` — `bestScore`,
      урезанный до физически возможного по времени, реально проведённому в бою
      (потолок потока врагов, `MAX_KILLS_PER_SEC`). Лидерборды Яндекса не
      проверяют присланное на сервере, так что это единственная доступная мера;
      от переписанного клиента она не спасает. Проверка: `npm run check:score`.
- ✅ Арт боссов не подменяется процедурными заглушками: листы грузятся фоном из
      BootScene и режутся по приходу каждого файла. Проверка: `npm run check:boss`.
- ✅ Звук и паузы по п.1.3, п.1.14, п.1.15 и п.4.7 проверяются автоматически:
      `npm run check:audio` (15 проверок — скрытая вкладка, реклама, две
      причины паузы разом, сохранение пользовательского мьюта, отсутствие
      своей заглушки о повороте, возврат на вкладку без события).
      Требует запущенный `npm run dev`.
- ✅ Музыка — два трека под CC0 с проверяемым источником, лицензия записана
      в теги файлов; подробности и ответ по п.3.5 — `dock/rights.md`.
- ✅ Нет внешних ссылок/переходов; нет сторонних сетей.
- ✅ Локализация полная: все сцены через `t()`, включая имена предметов
      (собираются в рантайме), названия endless-зон и единицы времени.
      Проверяется тестами — см. блок «локализация» в `tests/data.test.js`.
- [x] Скриншоты промо — 12 кадров реального геймплея (100% игрового экрана,
      без рамок и коллажей), 1280×720 16:9: `dock/screenshots/`.
      Пересобрать: `npm run dev`, затем `node tools/shots.mjs`.
      Английский комплект: `LANG_UI=en node tools/shots.mjs` → `dock/screenshots-en/`.
